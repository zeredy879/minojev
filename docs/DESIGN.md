# Design notes

minojev is a generation-free decision model: unstructured state plus
runtime-defined questions in, typed probability distributions out, with zero
output-token decoding.

## Decision primitives

| Primitive | Candidates | Output |
|---|---|---|
| `choice` | 2–255 described options | complete distribution over options |
| `boolean` | one proposition (optional true/false criteria) | `[P(false), P(true)]` |
| `score` | 2–10 ordered levels | level distribution + expected level |

All three are scored from a single forward pass. `decode_steps` is reported as
zero in every record.

## Path encoding

A candidate path is:

```
State:
<canonical state text>
Question type: <kind>
Question:
<instructions>
Candidate: <description>
Decision:
<eos>
```

Paths are split into a shared `state_ids` prefix and a `suffix_ids` tail.
`fresh` mode batches whole paths; `reuse` mode prefills each distinct state
once, replicates its KV cache across branches, and forwards only the suffixes.
Both modes are covered by an equivalence test.

## Decision head

One shared scalar scorer reads the final hidden state of each path. Choice and
boolean questions pass their candidate set through a small set-attention block
(candidates within a question attend to each other, with a
`log(candidate_count)` feature), which keeps the readout
permutation-equivariant and size-aware. Score questions softmax ordered level
logits and report `sum(i * p_i)`.

## Training

Teacher distributions are generated by construction in `minojev.synth`,
`minojev.maze`, `minojev.snake`, and `minojev.sokoban`, so training targets are
exact. Sokoban levels are generated by reverse play from a solved board; a
distance heuristic shapes the teacher and a breadth-first solver supplies the
optimal-move gold. Supported objectives are
`teacher_ce` (cross entropy to the teacher distribution), `gold_ce` (one-hot
gold), and `brier` (sum of squared differences). The head warms up with the
backbone frozen, then the whole model trains at a lower learning rate.
Checkpoints are selected on dev loss.

## Built-in backbone

`TinyLM` is a dependency-free decoder-only transformer with rotary positions
and a native KV cache. It trains from scratch on CPU in minutes, which keeps
the full pipeline reproducible offline. Hugging Face causal LMs can be used
through `minojev.logits` for zero-training native-logits readout.

## Claim boundaries

- Probabilities are conditional on the supplied candidates and are not
  calibrated operational confidence.
- The synthetic benchmarks demonstrate that the training and inference
  pipeline learns; they are not natural-language quality benchmarks.
- The tiny backbone is a testbed, not a reproduction of any released model
  weights.
